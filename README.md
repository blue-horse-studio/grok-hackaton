# Grok Hackaton

Proyecto para el **[Hackathon por Nuevo León x Grok Bot & AI Tinkerers](https://luma.com/monterrey-p7pu)**, parte de Monterrey Tech Week 2026.

- **Lugar:** Hangar 2, nivel 3, HUB de Innovación y Emprendimiento Eduardo Garza T., Tec Campus Monterrey
- **Formato:** equipos de hasta 4 personas, 2 horas para construir un prototipo de IA, demo frente a jueces
- **Retos:** agua, movilidad, calidad del aire, seguridad, salud y educación (o uno propio)
