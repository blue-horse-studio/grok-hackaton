# Storyboard — intro Forja NL (~75 s, 7 beats)

Style frames at 1920×1080: `frame-0N-*.svg` (editable, with ids on every layer) plus `frame-0N-*.png` (export).
The photos are linked by relative path (`../referencias/fotos/*.jpg`). If Figma doesn't resolve them when you import the SVG, drag in the JPG and use it as the fill of the layer with the same id (`foto-*`).
Constants:
- **Lines:** a thick white line (stroke 44 in frames, 22/240 in the symbol), flat ends, 45° chamfers.
- **Window:** the inside of every closed line is a window onto a photo.
- **Token:** a chamfered square (16 % chamfer).
- **Editorial details:** a thin line at the top, `0N / 07` in mono, and "FORJA NL" set vertically.
- **Frames 2 and 3** share the same grid (horizon, bridge, title) so the parallel "steel → cities / tokens → companies" reads without words.
- **Easing:** `power3.out` when a line draws, `expo.inOut` for camera moves and window openings.
